# 02 架构说明（TOGAF 四域视角）

> 项目：KPI 驾驶舱

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 让班组长 30 秒看全产线健康度，早会不再翻系统 |
| 数据架构 | KPI 行 → 派生指标（合格率/达成率）→ 文本表+JSON |
| 应用架构 | core 计算派生指标与等宽表；pipeline 输出并可探测 streamlit |
| 技术架构 | Python 3.12 + conda pp03；零依赖可跑；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 派生指标 + 等宽渲染 | `derive()/render()` |
| `io_utils.py` | JSON/文本落盘 | `write_json()/write_text()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
