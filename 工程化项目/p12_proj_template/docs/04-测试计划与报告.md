# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：标准工程模板生成　　文档版本：v1.1（2026-10-27 与代码同步修订）

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，`core`/`env_probe` 纯函数 + tmp_path | 覆盖正常/边界/异常三档 |
| 集成测试 | `pipeline.run()` 端到端（tmp_path，绝不碰 output/） | 输入配置 → 生成树 → 报告/JSON 链路正确 |
| 分层闸门测试 | tests/test_tier_gates.py 逐层取证 | D/C/B/A 每层都有可证伪数字，且能被单条配置翻掉 |
| 回归 | `pytest -q` 全量 + `verify_local.py`（双 PYTHONHASHSEED） | 任一改动不破坏既有行为与可复现性 |
| 负面约束 | 全部测试**不执行 git、不创建 venv**，只校验生成文件内容 | 防止测试污染课程包 / 误改仓库状态 |
