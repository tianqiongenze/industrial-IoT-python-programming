# 01 需求规格说明（GB/T 9385《计算机软件需求规格说明规范》）

> 项目：数据仓库 ORM（03-Python程序设计-项目实战 · W07 第13次课）
> 文档版本：v1.0　编制日期：2026-10-14　密级：教学内部

## 1. 范围
不写 SQL 也能操作数据库：手写一个极简 ORM（内存表+索引），支持条件查询、批量写入、外键约束与查询计划（是否走索引）。

## 3. 用户故事与验收标准
| 编号 | 用户故事 | 验收标准 |
|---|---|---|
| US-01 | 作为学员，我希望不写SQL也能查数据 | where() |
| US-02 | 作为工程师，我想知道查询有没有走索引 | explain() |

## 4. 功能需求
| 编号 | 功能点 | 说明 |
|---|---|---|
| F-01 | 建表 | 字段类型约束 |
| F-02 | 索引 | 倒排，O(1) 定位 |
| F-03 | 查询 | 等值/范围/多条件 |
| F-04 | 查询计划 | 是否走索引 |

## 5. 非功能需求
| ID | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| NF-1 | 可复现 | 固定随机种子，重复运行结果一致 | 二次运行 diff |
| NF-2 | 可移植 | 仅标准库 + 无；任意 conda 环境可跑 | 换机运行 |
| NF-3 | 可配置 | 全部阈值/清单在 config/rules.yaml | 改配置不改代码 |
| NF-4 | 可测试 | pytest 用例 ≥ 6，覆盖正常/边界/异常 | `pytest -q` |

## 6. 接口约束
- CLI：`python run.py [--config CONFIG] [--outdir DIR] [--quiet]`
- 配置：`config/rules.yaml`（格式见 docs/05）
- 输出：`output/report.txt`、`output/*.json`

## 7. 追踪性
本规格 ↔ docs/03 设计说明 ↔ tests/ ↔ 工单任务书 三层一一对应。
