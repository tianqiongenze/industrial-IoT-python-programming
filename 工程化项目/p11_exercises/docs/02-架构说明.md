# 02 架构说明（TOGAF 四域视角）

> 项目：Python 五题闯关

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 新员工入职测评：吴工按五题结果定岗定层（D/C/B/A） |
| 数据架构 | 题目输入输出样例即数据契约（每题≥3组：正常/边界/异常） |
| 应用架构 | 单入口 run() 调度 5 个互不耦合的函数 t1()~t5() |
| 技术架构 | Python 3.12 + conda pp03；零第三方依赖；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 五题纯函数实现 | `c_to_f()/quad()/crud()/plc()/safe_read()` |
| `io_utils.py` | 安全读文件 | `safe_read_lines()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
