## 2. 分支与提交规范
- 分支：`main` 保护；开发用 `feat/<工单号>-<简述>`、`fix/<问题>`
- 提交信息：`feat: ...` / `fix: ...` / `docs: ...` / `test: ...`
- 节奏：每周 ≥3 次 commit；合入 main 必须 `pytest -q` 全绿
- 实物载体：以上命令不再是口头约定——生成树里的 `scripts/setup_venv.sh`（C 层）与
  `scripts/git_dev_branch.sh`（B 层 `git branch dev` / `git checkout dev` / `git merge --no-ff`）
  逐条写明，且 `core.layer_facts()` 会回读这两个文件的内容来判定 B/C 层是否达标
