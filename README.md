## 决策三件套用法（每工单必做）

1. **备选方案对比**：工单内给出2-3个候选方案；
2. **决策矩阵**：小组按维度打分（0-5），结论写入工单并公示；
3. **决策追责**：第二轮实施后复盘——"如果当初选另一个方案？"
   实施失误必须回溯决策环节（写入反思改进）。
