# 07 架构决策记录 ADR-001：未安装可选依赖时用 requirements.txt 兜底而非 pyproject.toml

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
课堂机器可能无法安装新版 setuptools；requirements.txt 是最通用兜底

## 备选方案
A pyproject（墙）｜B requirements.txt（稳）｜C both（重复真源）

## 决策
**采用：B requirements.txt**

## 理由
最通用、最不易翻车；README 说明安装命令

## 后果
- 正面：构建能力弱
- 负面/代价：低
- 缓解：README 已写
