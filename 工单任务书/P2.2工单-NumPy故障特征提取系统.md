### 知识四要素详解（V1.2深度版·与授课PPT同源）

**B01 ndarray同构数组**
- 定义：ndarray=同规格集装箱阵列：同类型/shape量形状/dtype标材质
- 使用场景：向量化计算的地基——30维特征的容器
- 应用实例：X = np.array([[78.5, 4.2, …], …]); X.shape
- 扩展与误区：误区：往ndarray塞混合类型——异构先用Pandas再取.values
- 原理：ndarray同构数组：全元素同一类型、内存连续整块——比Python列表（每元素一个对象指针）省内存且缓存友好，这是快的物质基础
- 判断依据：数值矩阵运算（万点振动信号）一律ndarray；混合类型表格才是pandas的地盘
- 逐行解释：a=np.array([1.0,2.0,3.0]) dtype float64整块内存；a.dtype 看类型；a.nbytes 看实占字节——list要一个对象头一个指针，数组只存裸数
- 进阶优化：dtype选择：float32减半内存（精度够用时）；np.memmap超大数据映射磁盘按需读

**B02 向量化**
- 定义：向量化=整箱叉车vs逐件搬砖：底层C一次处理整块内存快10-100倍
- 使用场景：3000行特征提取<100ms的验收指标靠它
- 应用实例：(X - X.mean(axis=0)) / X.std(axis=0) 整列标准化
- 扩展与误区：误区：以为for循环只是慢一点——数据量大时是分钟vs毫秒的量级差
- 原理：向量化=把Python层循环下沉到C层整块执行：a*2是一个C for不是一万个Python解释器调度——快百倍的原理在此
- 判断依据：凡'对每个元素做同样运算'的循环都该消失：for换成向量式表达式
- 逐行解释：%timeit [x*2 for x in lst] 慢；%timeit a*2 快两个数量级——解释器开销摊到整块上，单点成本趋近C
- 进阶优化：np.where(cond,x,y)向量版三目；np.vectorize仍是循环的糖衣（不快）；真·快靠ufunc与切片视图

**B03 广播**
- 定义：广播=小矩阵自动复印对齐：列均值(30,)摊到3000行每行相减
- 使用场景：每个样本减同一均值——一行代码全样本
- 应用实例：X - X.mean(axis=0) 形状(3000,30)-(30,)
- 扩展与误区：误区：维度不匹配想当然——从右往左对齐，缺的补1，不匹配报错
- 原理：广播=小形状自动'拉伸'适配大形状：列向量(3,1)+行向量(1,4)→(3,4)不拷贝数据——维度从右对齐、缺维当1、1可扩
- 判断依据：每行减去各自均值这类'批量平移'：mat-means[:,None] 一行完成—— broadcasting是NumPy的灵魂
- 逐行解释：mat-a[None,:] 每列减a；mat-a[:,None] 每行减a；(1000,3)%(3,) 列数对齐自动逐行广播——newaxis手动加维是常用技巧
- 进阶优化：广播失败报operands could not be broadcast先查shape（print(a.shape)）；大数组广播临时内存翻倍要留意

**B04 rfft频域**
- 定义：rfft=声音拆音叉：时序信号拆成正弦成分——频域找主频指纹
- 使用场景：振动信号找主频——频域指纹识别故障模式
- 应用实例：spec = np.abs(np.fft.rfft(x)); 幅值×2/n补偿
- 扩展与误区：误区：fft结果直接用——复数要取abs才是幅值，忘×2/n小一半
- 原理：rfft把时域信号变频域：真实信号只需正频率半谱——横轴从'第几个采样点'变'多少Hz'，看清振动的成分
- 判断依据：时域看不出周期混杂（多故障叠加波形），频域一分解：50Hz工频干扰/120Hz轴承特征频率各归各位
- 逐行解释：F=np.fft.rfft(vib) 变换；freqs=np.fft.rfftfreq(N,d=1/fs) 频率轴（fs采样率d间隔）；np.abs(F) 取幅值——三行出频谱图
- 进阶优化：加窗np.hanning(N)抑制频谱泄漏；irfft反向还回时域；进阶welch功率谱密度平均降噪

**B05 峭度与偏度**
- 定义：峭度=冲击探测器(尖峰多则大)；偏度=歪斜度(拖尾朝哪边)
- 使用场景：无需标注的无监督健康指标——轴承点蚀高峭度
- 应用实例：from scipy.stats import kurtosis; kurtosis(x)
- 扩展与误区：误区：峭度>3才有冲击成分——正态分布基准是3不是0
- 原理：峭度(kurtosis)衡量'尖不尖'（正常≈3，冲击故障>4急升）、偏度(skewness)衡量'歪不歪'——波形形状的两个数字指纹
- 判断依据：轴承点蚀产生周期冲击→峭度飙升，比看均值/std敏感得多——30维特征里的两位'哨兵'
- 逐行解释：from scipy.stats import kurtosis,skew; kurtosis(vib) 冲击度；skew(vib) 偏斜方向——健康泵峭度≈3持续监测，破4预警
- 进阶优化：滚动轴承特征频率对照表（BPFO/BPFI）可定位损伤部件；峭度对离群敏感，先去毛刺再算

**B06 主频=谱峰位置**
- 定义：主频=频谱最高峰的位置——设备的'嗓音音调'，故障会变调
- 使用场景：不同故障对应不同特征频率——频域诊断的钥匙
- 应用实例：spec.argmax()取谱峰下标×频率分辨率
- 扩展与误区：误区：只看最高峰——谐波峰也可能异常，二倍频常是松动信号
- 原理：主频=频谱幅值最大的谱峰位置：argmax找峰、频率轴取值——'这台设备在以多少Hz振动'一句话答案
- 判断依据：转速3000rpm=50Hz，主频漂移说明转速不稳；出现非工频新峰=新振源——一峰一诊断
- 逐行解释：idx=np.argmax(np.abs(F)) 找最大幅值下标；main_freq=freqs[idx] 换算Hz——两行锁定主振动频率
- 进阶优化：峰群分析（前3峰及占比）比单主频信息更全；包络分析解调轴承冲击——设备诊断进阶课

**B07 标准化防泄漏**
- 定义：scaler只fit训练集=考官先定评分标准，考生(测试集)只准用同标准
- 使用场景：数据泄漏是模型虚高的头号元凶
- 应用实例：scaler.fit(X_train); X_test_s = scaler.transform(X_test)
- 扩展与误区：误区：fit在测试集上=偷看答案——线上线下不一致的根源
- 原理：标准化防泄漏=mean/std只能从训练集算：先split后fit——若用全量数据算再切分，测试集信息就渗进了训练（成绩虚高）
- 判断依据：任何 preprocessing（标准化/编码）都只能见训练集——这是ML工程第一军规
- 逐行解释：scaler.fit(X_train) 只喂训练集；scaler.transform(X_test) 测试集只变换不参与统计——错序：fit(全量)再split=泄漏，线上必露馅
- 进阶优化：Pipeline([('scaler',StandardScaler()),('model',...)])一步封死泄漏路径；交叉验证里fit永远在折内
