# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：Python 五题闯关（工单 P1.1）　执行环境：conda `pp03` / Python 3.12.11 /
> pytest 9.1.1　复现口令：`python -m pytest -q -p no:cacheprovider`

## 1. 测试策略
| 层级 | 方法 | 范围 | 证据 |
|---|---|---|---|
| 单元测试 | pytest，`core` 纯函数 | 每个函数正常 + 空输入 + 极值 + 异常四档 | `tests/test_core.py`（63 项） |
| 配置测试 | 双解析器（PyYAML ↔ `yaml_lite`）一致性、死配置告警、校验拒绝、工单四档线值 | `tests/test_config.py`（29 项） |
| 题层测试 | `exercise1..5` 输出契约与配置联动 | `tests/test_exercises.py`（6 项） |
| 内置断言 | `selfcheck` 50 条断言表（含边界 37 条） | `tests/test_selfcheck.py`（5 项） |
| 工单档位验收 | 及格(D)/良好(C)/优秀(B)/超优(A) 各一文件，逐条实测证据 + 可证伪样例 + "只改配置就能翻档"；含课堂保底组（不占工单字母） | `test_tier_d/c/b/a.py`（14/14/13/12 项） |
| 规范度量 | 脏/净源码双向样例 + 真实项目实测 + 逐文件得分明细 | `tests/test_stylecheck.py`（9 项） |
| 端到端 | `run.py` 子进程 + tmp_path 沙箱 + 两次运行字节比对 + 报告↔JSON `tiers` 逐字一致 + 四档判定与配置翻档 | `tests/test_pipeline_cli.py`（24 项） |
