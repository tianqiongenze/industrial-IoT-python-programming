# 02 架构说明（TOGAF 四域视角）

> 项目：特征工厂

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 把'凭经验挑特征'变成可复用的特征工厂，模型效果可追溯 |
| 数据架构 | 振动窗口 (1000×1000) → 30 主特征（时域 10＋频域 15＋统计 5）＋5 衍生＝35 列 → 标签；输出特征表(npy/csv)＋特征字典＋μ/σ＋重要性 |
| 应用架构 | core 造信号/提特征/恒等式对账/去冗余；pipeline 做防泄漏标准化、RF 重要性排序、去冗余取舍与箱线图/热力图，并输出 D/C/B/A 四级达标证据 |
| 技术架构 | Python 3.12 + conda pp03；numpy/scikit-learn/matplotlib（图可缺省）；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口（真实函数名） |
|---|---|---|
| `config.py` | YAML → `Settings`（点号路径取值）＋启动校验；无 PyYAML 时降级 `yaml_lite` | `load_config()` `Settings.from_dict()` `_validate()` `yaml_lite()` |
| `core.py` | 纯函数领域逻辑（零 IO）：信号合成、30＋5 特征、标准化/切分、相关去冗余、恒等式 | `make_signals()` `spectrum()` `Ctx` `extract_primary()` `extract_derived()` `extract()` `zscore_fit()` `train_test_idx()` `corr_matrix()` `drop_redundant()` `identity_devations()` |
| `vector_check.py` | C 层向量化静态闸门（AST 扫 `core` 的 12 个特征函数） | `scan()` `scan_text()` `classify()` `detail_lines()` `summary_text()` |
| `io_utils.py` | CSV/JSON/文本原子落盘、输入指纹 | `write_csv_rows()` `write_json()` `write_text()` `sha256_short()` |
| `report.py` | 分节等宽报告（默认不写墙钟时间戳） | `render()` `save()` `console()` |
| `pipeline.py` | 编排：取数 → 特征 → 标准化 → 模型/去冗余 → 图 → 落盘 → 报告；四级闸门判定 | `run()` `build()` `ledger()` `sections()` `result_json()` |

## 依赖方向
```
run.py  →  pipeline ─┬→ config（YAML 驱动）
                     ├→ core（纯函数，只依赖 numpy）
                     ├→ vector_check → core（AST 扫源码）
                     ├→ report → io_utils
                     └→ io_utils
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）；
`config` 与 `core` 互不依赖，`vector_check` 只读 `core` 的源码与特征名注册表。

## 数据口径
`core.make_signals()` 的合成模型（可覆盖的量全部是 `config/rules.yaml` 入参）：
0.5 直流偏置 ＋ 1×f0 与 2×f0 两条线谱 ＋ 高斯随机振动 ＋ 磨损类专属的稀疏冲击串。
关键设计是**功率守恒**：looseness `u∈[0,1]` 只决定线谱功率在 1× 与 2× 之间怎么分
（`A1=√(2P(1−u))`、`A2=√(2P·u)`，`P=signal.tone_power=0.008`），两类总能量相同。

- **为什么守恒**：若故障类"更响"，`std/rms/var/peak` 就成了捷径判别器，`a16` 的榜首是被假信号
  抬起来的；守恒之后唯一证据链变成"能量坐在哪条谱线上"，`a16` 才凭实测坐稳重要性第 1 名（0.1851）。
- **每窗独立** `u`／初相／噪声底（`noise_low=0.14`~`noise_high=0.18`）：省略这一步，35 列特征会被
  类间差异整体主导，｜r｜≥0.95 的对数虚高、A 层去冗余失真。
- **磨损类叠加稀疏冲击**（`impact_amp=0.9` × `impact_rate=0.02`，调制载波 33Hz）与 3×f0 分量：
  正常类峭度中位 2.905（教科书基线 3）、磨损类 5.375 ⇒ B05「峭度哨兵」与 warn/danger（4/6）
  能落到真实计数上（预警 474 个／停机 146 个样本）。
- **二倍频指纹**：a16 中位 正常 0.0306 → 磨损 0.1099，能量迁移约 3.60 倍。
- **真实数据链**：`signal.source=clean` 时不吃合成器，而按 `io.clean_csv` 读 P2.1 的 `clean.csv`，
  以 `window_length=64`／`window_stride=32` 重叠滑窗切窗，标签取自 `signal.fault_devices` 清单。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置；墙钟时长写在 `output/` 之外的 `../runtime/timing.json`，
  因此 `output/` 换 `PYTHONHASHSEED` 重跑逐字节一致
