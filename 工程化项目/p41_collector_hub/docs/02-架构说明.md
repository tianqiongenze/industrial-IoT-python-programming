# 02 架构说明（TOGAF 四域视角）

> 项目：多源数据采集中枢

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 设备数据可靠汇聚为集团级数据底座 |
| 数据架构 | 各源寄存器原值 → ÷scale 还原 → batch；对账恒等式 Σ批次=Σ单条 |
| 应用架构 | core 生成读数/换算/切批/对账；pipeline 轮询多轮并统计 |
| 技术架构 | Python 3.12 + conda pp03；零依赖可跑（pymodbus 可选）；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 读数生成/换算/对账/退避 | `read()/restore()/reconcile()/sleep_with()` |
| `io_utils.py` | JSON 落盘 | `write_json()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
