# 02 架构说明（TOGAF 四域视角）

> 项目：标准工程模板生成

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 把"新人第一天的手工建目录 + 抄 git 命令"变成一键规范骨架 + 分层达标证据，减少不规范代码的源头 |
| 数据架构 | 项目名/运行依赖/开发依赖/闸门工具清单/两个开关 → 生成 15 个标准文件 + `output/report.txt` + `output/result.json` |
| 应用架构 | 模板文件用 `core.file_templates()` 表驱动管理；新增文件=改表，不改逻辑；分层判定与模板分离（`layer_facts` → `layer_gates`） |
| 技术架构 | Python 3.12 + conda pp03；仅标准库（PyYAML 缺失时 `yaml_lite` 兜底）；pytest；**不依赖 black/flake8/pre-commit 可导入** |

## 分层与模块职责
| 模块 | 职责 | 关键接口（与源码逐一对应） |
|---|---|---|
| `config.py` | YAML 加载 + 缺省兜底 | `load_config()` / `Settings.from_dict()` / `yaml_lite()` / `DEFAULTS` |
| `core.py` | 模板定义 + 生成器 + 自检 + 分层事实与闸门 | `file_templates()` / `ensure()` / `verify()` / `inventory()` / `pre_commit_text()` / `requirements_text()` / `requirements_dev_text()` / `pyproject_text()` / `dep_lines()` / `pinned()` / `hook_ids()` / `hook_entries()` / `req_names()` / `scripts_text()` / `resolve_scripts()` / `layer_facts()` / `layer_gates()` / `structure_ok()` / `WO_ROW` / `workorder_gates()` / `skeleton_smoke()` / `conda_env()` / `_ci_workflows()` |
| `env_probe.py` | A 层工具可导入性真实探测（不执行工具） | `probe()` / `detect()` / `usable_names()` / `missing_names()` / `summary()` / `hook_coverage()` / `report_lines()` |
| `io_utils.py` | 原子写 / JSON / CSV / 等宽表 | `write_text()` / `write_json()` / `read_json()` / `fmt_table()` |
| `report.py` | 四段式报告渲染与落盘 | `render()` / `save()` / `console()` |
| `pipeline.py` | 编排：生成 → 盘点 → 探测 → 进程内真跑生成骨架 → 工单四行对照 + 分层达标 → 落盘 | `run()` / `_b()` / `_wo_lines()` |
| `cli.py` | argparse 入口（run.py 与 `[project.scripts]` 共用） | `build_parser()` / `main()` |

## 依赖方向
```
run.py ──→ cli ──┬──→ config            （rules.yaml → Settings，DEFAULTS 兜底）
                 └──→ pipeline ──┬──→ core        （模板表/生成/自检/分层事实与闸门）
                                  ├──→ env_probe   （闸门工具可导入性探测，不改环境）
                                  ├──→ io_utils    （result.json 落盘）
                                  └──→ report ──→ io_utils（report.txt 落盘）
```
**规则**：下层不得反向依赖上层；`core` 不调用 `io_utils`/`env_probe`（保持可单测）；
`pipeline` 是唯一把"模板事实 + 环境探测 + 报告"拼起来的地方；全链路零外部命令。

## 关键质量属性
- **可测试性**：`core` 的模板/解析函数是纯函数，落盘函数只收发路径 → 单测无需 mock
- **可配置性**：项目名、双清单依赖、闸门工具、`emit_pre_commit`、`overwrite_existing` 全外置 YAML
- **可复现性**：`output/` 内除头部一条"生成时间"外全部确定；状态相关的计数（新写/保留个数）不进报告
- **诚实性**：A 层只声明钩子文件与探测结论，本机缺 black/flake8 就写"未运行"，不冒充执行结果
