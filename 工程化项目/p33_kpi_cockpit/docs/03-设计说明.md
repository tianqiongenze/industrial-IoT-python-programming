## 2. 核心算法/规则
三条主线全部是 `core.py` 纯函数，CLI 与仪表盘共用（工程化要求 1：计算与渲染分离）：

1. **KPI 计算**（`compute_kpis`）：名称与顺序由 `config/rules.yaml` 的 `kpi.required`（5 个必做）
   + `kpi.extra`（4 个补充，满足 ≥7）驱动；良率用**加权口径**（合格总量/总产量）抗小样本噪声；
   设备在线数按"每台设备末条记录状态"判定；效率对标 = 实际产量 /（单日目标 × 窗口天数），
   截断到 1.0 供 `st.progress` 消费；配置写了代码未实现的指标名 → 启动即 `ValueError`。
2. **红绿灯**（`tone`/`_item_tone`/`device_status`）：阈值全部来自配置（`warn` 黄线、`danger` 绿线），
   ≥danger 绿、≥warn 黄、否则红；"越高越坏"类指标（告警数、最高振动）单独定调，
   `st.metric` 对应 `delta_color="inverse"`，杜绝拿涨跌方向想当然。
3. **联动明细（A 层钻取）**（`drill_rows`/`drill_fingerprint`）：把前端选择事件
   （`selection_event.selection["points"]` 或 `st.dataframe` 行选择）翻译成明细行——
   点含 `x`/`ts` → 时间桶前缀匹配；含 `device_id` → 设备双条件；含 `row`/行号 → 命中该行并
   展开为"该设备该日"整段明细；脏点/越界/空选择一律防御性忽略。输出按原时序去重、
   列裁剪到 `drill.detail_columns`、行数截到 `drill.max_rows`（改配置不改代码）。
   结果指纹用 **zlib.crc32** 规范序列化（builtin `hash()` 受 PYTHONHASHSEED 随机化，不可作证据），
   CLI 报告中的「联动钻取证据」行即离线复放同一函数得到，可被任何人重算证伪。

## 3. 异常处理策略
| 异常 | 触发场景 | 处理 | 对应测试（真实节点名） |
|---|---|---|---|
| FileNotFoundError | 配置文件缺失 | 抛出并提示路径 | `tests/test_config.py::test_missing_config_raises` |
| ValueError | 阈值顺序颠倒（warn≥danger） | `Settings.from_dict` 启动即拒绝 | `tests/test_config.py::test_load_default_config`（合法配置反证）|
| ValueError | 效率对标目标非正 | 立即失败，不输出无意义百分比 | `tests/test_core.py::test_efficiency_rejects_non_positive_target` |
| ValueError | 配置含未实现 KPI 名 | 启动即失败并提示同步 core | `tests/test_core.py::test_compute_kpis_rejects_unknown_kpi_name` |
| ValueError | 数据源 0 行 / 脏 ts | 装载即拒绝 | `tests/test_data_source.py::test_dataset_rejects_empty_source` |
| ValueError | 筛选后 0 行 / 设备不存在 | CLI 显式报错，app 侧回退+警告 | `tests/test_pipeline.py::test_empty_window_raises`、`::test_unknown_device_raises_with_candidates` |
| 静默忽略 | 前端选择点脏/越界（非 dict、row=999 等） | `drill_rows` 防御跳过，仪表盘不白屏 | `tests/test_core.py::test_drill_rows_malformed_or_out_of_range_points_ignored` |
| RuntimeError | 日报耗时超预算（工单 P3.2） | 运行即失败 | `tests/test_pipeline.py::test_budget_violation_raises_rather_than_passing_quietly` |

## 4. 命名与代码规范
- PEP 8；`snake_case`（函数/变量）、`PascalCase`（类）、`UPPER_CASE`（常量）
- docstring 三件套：做什么 / 参数 / 返回
- 单元函数 ≤40 行，超过则拆分
