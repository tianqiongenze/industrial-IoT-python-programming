# 05 运行手册

## 1. 环境准备
```bash
conda create -n pp03 python=3.12 -y
conda activate pp03
pip install -r requirements.txt      # 项目内清单只锁 pandas；课程根另有 ../../requirements.lock 总清单
```

## 2. 运行
```bash
python run.py                     # 默认配置
python run.py --config config/rules.yaml
python run.py --outdir output/
python run.py --quiet             # 只落盘，不打印控制台
python run.py --no-bench          # 跳过 100 万行压测（课堂快跑；默认会跑）
python run.py --peek              # 课前导学：只摸底预览，不写 output/
python run.py --incremental       # 按 output/state.json 基线只处理新行并追加 clean.csv
python run.py --stamp             # 报告头写墙钟（破坏逐字节复现，默认关闭）
```

## 3. 配置说明（config/rules.yaml）
| 键 | 含义 | 默认 |
|---|---|---|
| warn | 预警线 | 80.0 |
| danger | 危险线/停机线 | 95.0 |
| unit | 单位口径 | c |
| seed | 随机种子（可复现） | 7 |
| topk | 检索/排序取前 k | 3 |
| pep8_pass_rate | D 档 PEP 8 子集达标线（%，内置 stylecheck 实测口径） | 75.0 |
| pep8_pass_rate_high | B 档 PEP 8 子集达标线（%，须 ≥ D 线，启动校验） | 85.0 |

## 4. 输出物
| 文件 | 内容 |
|---|---|
| output/report.txt | 完整过程报告（过程性证据）；§14 PEP 8 实测、§15 工单四档逐档判定＋保底自检 |
| output/result.json | 结构化结果（供下游/答辩取数），`tiers` 键为四档判定字典 |
| output/clean.csv | 清洗结果，仅导出 5 个必需列，本次 1186 行（按 device_id＋ts 排序） |
| output/clean_log.txt | 每步"操作→行数→理由"台账，本次 8 步 70 行 |
| output/missing_strategies.csv | 三策略缺失对比（dropna／中位数／组内插值），A 层决策矩阵 |
| output/anomalies.csv | 被剔异常留痕，本次 14 行，带 `hit_stat`/`hit_business` 双旗标 |
| output/state.json | 增量基线：`baseline_rows` ＋ 每设备最大时间戳（供 `--incremental`） |
| runtime/bench.json | 压测**秒数/吞吐**等波动指标——刻意不进 output/，否则会破坏逐字节复现 |

## 5. 常见问题
| 现象 | 原因 | 处置 |
|---|---|---|
| `ModuleNotFoundError` | 未安装依赖 | `pip install -r requirements.txt` |
| 配置不生效 | 未传 --config | 使用默认 `config/rules.yaml` |
| 中文乱码 | 控制台编码非 utf-8 | `set PYTHONIOENCODING=utf-8` |
