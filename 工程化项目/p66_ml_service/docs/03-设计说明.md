# 03 设计说明

> 项目：故障诊断模型与边缘部署（sklearn 五步流 + 标准库 HTTP 服务）

## 1. 模块清单与接口
见 docs/02 表。核心设计点：

- **特征契约单源**：`FEATURE_NAMES`（data.py:14）30 维列序是训练/服务/联动三方的
  同一份清单；`validate_feature_names`（data.py:24）维数≠30 或重名即 ValueError。
  manifest 落盘前再校验一次（core.py:175 save_model），杜绝"匿名 model.joblib"。
- **五步流纪律**：core.evaluate（core.py:73）严格按 分层划分(core.py:87)→fit→
  cross_val_score(core.py:93)→GridSearchCV(core.py:113)→在**测试集只评一次**选优
  (core.py:135/138 CM/precision/recall)。测试集不参与调参——先看测试集再调参=作弊。
- **A层三维评价（工单 03-P6）**：core.top_features（core.py:39）对 LR 取 `coef_`
  （正类=磨损，带符号值给方向）、对 RF/GBM/RF-tuned 取 `feature_importances_`，
  按 |权重| 降序出 Top-k（k=explain_topk，超出特征数自动钳制）；并列按
  `zlib.crc32(特征名)` 稳定定序（禁用 PYTHONHASHSEED 随机的内置 hash()）。
  训练耗时 fit_ms 用 `time.perf_counter` 实测，仅经 `timing_out` 出参交
  pipeline 写 runtime/train_timing.json（pipeline.py:78-89），**不进 output/**。
- **分层达标闸门**：pipeline._tier_gates（pipeline.py:171）按工单 cell-0 分层表
  逐条可证伪判定 D（跑通出结果）/C（F1≥0.80 并保存）/B（对比+调参+联动回写>0）/
  A（三维评价齐备），tiers 布尔进 result.json，判定行带真实数字进报告「分层达标」段。
- **工单验收四档对照**：pipeline.WO_ROW（逐字照抄工单 P6 四行）+ `_workorder_gates()`
  另起一节判 **及格/良好/优秀/超优**，与上面的课堂四档错一档、互不覆写；
  service.error_selftest() 真打 8 类请求取证 400/404，bench 的客户端/服务端两侧条数比对取证压测，
  教师包与新模型逐条比预测取证『版本对比实验』；ONNX 不可得就如实写不可得。
- **门禁硬阻断**：core.gate(core.py:170)；pipeline.py:53-54 不达标即
  `RuntimeError("评估门禁未通过…拒绝注册上线")`，工件不落盘。
- **P5 联动**（bridge.py:124 run_link）：P5 warehouse.db **拷贝**到
  output/warehouse_diagnosis.db（绝不回写 P5 原库）→ records ALTER 加
  diagnosis/diagnosis_proba/diagnosis_note（bridge.py:130-132）→ 每设备最近 32 条
  vib 窗口抽 30 维特征（bridge.py:66，列序=FEATURE_NAMES）→ predict_row → UPDATE
  最新记录；P5 库缺失时用同构替代表（bridge.py:25 STAND_IN_SQL）并如实注明来源。
  诚实口径：P5 记录分布与 P2.2 训练域不同，本表演示**机制**而非工况判定。
- **服务**（service.py:28 create_server）：ThreadingHTTPServer + 模型加载一次 +
  threading.Lock 串行推理；/health 真推理一发；/predict 校验 JSON→list→长度=30→
  全有限数，任一失败 400（JSON 错误体含 detail/hint）；未知路径 404（routes 列表）；
  log_message 改走 logging。测试用 **port=0** 起真服务真调用，`--serve` 用配置端口。
- **压测可复现策略**：service.bench（service.py:133）真实 HTTP 往返：warmup 首发
  （含首推理开销）+ n 次取 mean/p50/p95/p99/max/QPS；首跑/`--bench` 实测固化
  output/bench.json，默认运行（或 `--no-bench`）读缓存 ⇒ 两次运行除
  trained_at/生成时间外逐字节一致（test_tier_gates 以字节 diff 取证 --no-bench）。
- **ONNX 探测**（onnx_export.py:11）：`try: import skl2onnx` 缺依赖**不堆栈报错**，
  返回 `{"available": False, "reason": ...}` 写入报告；装上即自动导出+onnxruntime
  延迟对比。A 层结论如实：当前离线环境不可得，计划 opset 17。

## 2. 核心算法/规则
本项目核心算法=「五步流评估 + A层三维评价」：同一份 30 维特征契约上，先 stratify
划分并把测试集锁到最后只碰一次；LR/RF/GBM 三候选各自 cross_val_score 留 CV 均值±方差，
RF 再过 GridSearchCV 网格调参；以测试集 macro-F1 定选并出混淆矩阵/每类精确率召回率，
F1<min_f1 硬阻断拒绝注册。定选之后补 A 层工单要求的另外两维：训练耗时 fit_ms
（墙钟 perf_counter，只写 runtime/）与可解释性 Top-k（LR 看 |coef|、树模型看
feature_importances_，crc32 稳定破并列），三维证据全部落进报告与 result.json。

| 环节 | 实现 | 说明 |
|---|---|---|
| 划分 | train_test_split(stratify=y, test_size=0.25, random_state=seed) | 保类别比例 |
| CV | cross_val_score(est, X, y, cv=cv_folds, scoring="f1") | 均值±方差进对比表 |
| 调参 | GridSearchCV(RF, n_estimators×max_depth, cv) | best_params_/cv_results_ Top5 留痕 |
| 选优 | 测试 macro-F1 在 LR/RF/GBM/RF-tuned 中定选 | 测试集只碰一次 |
| 门禁 | macro_f1 ≥ min_f1(0.80) 否则 RuntimeError | 不达标不落盘不上线 |
| 可解释性 | top_features：LR=coef_（正类），RF/GBM=feature_importances_；排序键 (-abs, zlib.crc32(名))，k=explain_topk(3) | 确定性 Top-k 表进 report.txt 与 result.json |
| 训练耗时 | time.perf_counter 实测 fit_ms → runtime/train_timing.json | 墙钟值禁入 output/（repeat 字节闸门） |
| 分层达标 | _tier_gates：D 跑通出结果/C F1≥0.80 并保存/B 对比+调参+联动/A 三维评价 | 每行带真实数字，tiers 进 result.json |
| 工单四档对照 | _workorder_gates：
及格(D) 模型文件可加载+服务接口可调通
                      良好(C) F1≥0.80 并保存模型；压测 P95<100ms
                      优秀(B) 模型对比+调参记录；服务异常处理(404/参数错)
                      超优(A) 优秀+边缘侧模型格式转换(ONNX/TensorFlow Lite)或版本对比实验
  有未取证子项的行只写「本节取证项 通过」 | 四行原文逐字进 result.json（workorder_rows），
  子项点名列进 workorder_unmeasured；探针/延迟/版本对比数字进 workorder_evidence |
| 窗口特征 | 32 点 vib→时域15+频域15（rfft），列序=FEATURE_NAMES | bridge.features_from_window |
| 服务并发 | ThreadingHTTPServer+Lock | sklearn 预估线程不安全，锁内串行 |
| 压测 | warmup 5 发+p50/p95/p99（非均值） | 验收看 p95 |

## 3. 异常处理策略
| 异常 | 触发场景 | 处理 | 对应测试 |
|---|---|---|---|
| RuntimeError | 门禁不达标 | 拒绝注册上线，退出非零 | test_pipeline.py::test_gate_hard_block |
| ValueError | 特征维数≠30 / manifest 列序坏 / NaN | 服务回 400；predict_row 直接抛 | test_service.py::test_predict_wrong_dimension_400、test_core.py::test_predict_row_dimension_guard |
| FileNotFoundError | 模型工件/配置缺失 | 明确提示先训练/给路径，不静默 | test_config.py::test_missing_config_raises、test_core.py::test_save_and_manifest_roundtrip |
| HTTPError(404) | 未知路径 | JSON 返回 routes 清单 | test_service.py::test_unknown_path_404 |
| InconsistentVersionWarning | 教师包跨 sklearn 版本 | catch_warnings **如实转录**进报告（本次无告警即写"无"） | pipeline._teacher_check |

## 4. 命名与代码规范
- PEP 8；snake_case（函数/变量）、PascalCase（类/Handler）、UPPER_CASE（常量）
- docstring 三件套：做什么/参数/返回；单元函数 ≤60 行
- 工件命名带版本：model_v1.joblib（教材 B01 反例"model.pkl"刻意规避）
