## 2. 分支与提交规范（工单口径，本仓库不在课程项目内自动执行 git）
- 分支：`main` 保护；开发用 `feat/<工单号>-<简述>`、`fix/<问题>`。
- 提交信息：`feat: ...` / `fix: ...` / `docs: ...` / `test: ...`（工单 P1.2 有
  `gitflow` 模块专门生成并校验该序列；本项目只遵循约定，不代跑 git）。
- 节奏：每周 ≥3 次 commit；合入 main 前 `python -m pytest -q` 必须全绿。
- 建议的首轮提交拆分：
  `feat: 五题实现与配置驱动` → `test: 分层用例与边界断言` →
  `docs: 迁移笔记与追踪地图`。
