# 02 架构说明（TOGAF 四域视角）

> 项目：特征工厂

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 把'凭经验挑特征'变成可复用的特征工厂，模型效果可追溯 |
| 数据架构 | 振动窗口 → 13维时域+4维频域 → 标签；输出特征表+重要性 |
| 应用架构 | core 造信号/提特征/训练排序；pipeline 输出 Top-N 与可解释结论 |
| 技术架构 | Python 3.12 + conda pp03；numpy/sklearn；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 信号生成 + 13+4 特征 | `make_window()/feats_time()/feats_freq()` |
| `io_utils.py` | CSV/JSON 落盘 | `write_csv_rows()/write_json()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
