> 项目：KPI 驾驶舱

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，core 纯函数 | 覆盖正常/边界/异常三档（含 drill_rows 脏点/越界/空选择） |
| 集成测试 | pipeline 端到端（临时目录） | 输入→输出链路正确、分层达标数字可复算 |
| UI 无头回归 | streamlit.testing.v1.AppTest 执行同一份 app.py | 不启浏览器证明仪表盘真能跑（禁 `streamlit run` 进测试） |
| 闸门测试 | tests/test_tier_gates.py + tests/test_workorder_rows.py | D/C/B/A 每条拿出真数字证据；改配置可让闸门判不达标（可证伪）；四行行首逐字对表工单原文 |
| 入口回归 | tests/test_entrypoints.py | pyproject `[project.scripts]` 声明的 `kpi_cockpit.cli:main` 必须解析为可调用对象 |
| 回归/确定性 | `pytest -q` 全量 + verify_local 双 PYTHONHASHSEED 复跑 | 任一改动不破坏既有行为；output/ 不含墙钟数字 |
