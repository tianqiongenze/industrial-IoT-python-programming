# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：Pandas 数据清洗管道

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，core 纯函数 | 覆盖正常/边界/异常三档 |
| 集成测试 | `pipeline.run_pipeline()` 端到端（内存表，不落文件） | 输入→清洗→评分→门禁链路正确 |
| 档位闸门 | `tests/test_workorder_tiers.py` 在 tmp 目录跑真实完整 `pipeline.run()` | 工单四行逐档判实测证据；纯配置翻转证明闸门真会咬合而非恒真 |
| 入口回归 | `tests/test_entrypoints.py` 解析 pyproject 的 `[project.scripts]` 目标 | `pd_clean.cli:main` 必须能导入且可调用 |
| 回归 | `pytest -q` 全量 | 任一改动不破坏既有行为 |
