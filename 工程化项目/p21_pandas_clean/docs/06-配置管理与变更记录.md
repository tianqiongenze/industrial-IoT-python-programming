## 2. 分支与提交规范
- 分支：`main` 保护；开发用 `feat/<工单号>-<简述>`、`fix/<问题>`
- 提交信息：`feat: ...` / `fix: ...` / `docs: ...` / `test: ...`
- 节奏：每周 ≥3 次 commit；合入 main 必须 `pytest -q` 全绿
