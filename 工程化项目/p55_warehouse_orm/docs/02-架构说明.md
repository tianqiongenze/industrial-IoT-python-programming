# 02 架构说明（TOGAF 四域视角）

> 项目：数据仓库 ORM

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 让不熟悉 SQL 的学员也能可靠操作数据，并理解'为什么慢' |
| 数据架构 | 内存表（list of dict）+ 倒排索引；查询计划标注是否走索引 |
| 应用架构 | core 提供 Table/index/查询计划；pipeline 批量造数+对比演示 |
| 技术架构 | Python 3.12 + conda pp03；零第三方依赖（sqlite3 可选）；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 极简 ORM：建表/索引/查询/计划 | `Table/create_index()/where()/explain()` |
| `io_utils.py` | JSON 落盘 | `write_json()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
