## 1. 范围
C 底子转 Python 的五道标准题：①温度单位换算器（℃→℉ 与 ℃→K，两个结果都
要）②一元二次方程求解（含 Δ<0 无实根分支）③设备清单增删改查（字典）
④`Device` 基类 + `PLC` 子类（新增 scan_ms 且覆盖 start()，另有 scan 行为）
⑤异常保护的文件读取器。每题一个函数，主函数只做调用与输出。
