# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：多源数据采集中枢

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，core 纯函数（transport 用 `flaky()` 桩注入） | 覆盖正常/边界/异常三档 |
| 集成测试 | pipeline 端到端（临时目录，同一份 config/rules.yaml） | 输入→输出链路正确、分层达标数字可复算 |
| 闸门测试 | tests/test_tier_gates.py | D/C/B/A 每条拿出真数字证据；只改配置即可让闸门判不达标（可证伪） |
| 工单逐档对表 | tests/test_workorder_rows.py | 工单四档（及格/良好/优秀/超优）逐档实测取证；报告行首逐字引用 `pipeline.WO_ROW`，且该常量必须等于课程仓 `工单任务书/P4工单-多源工业数据采集系统.md` 的验收表原文 |
| 文档-配置对齐 | tests/test_config.py::test_docs05_param_table_matches_rules_yaml_keys_and_defaults | 手册 §3 参数表与 config/rules.yaml 键名、默认值逐字对齐（键不多不少），防止「改配置忘改手册」 |
| 回归 | `pytest -q` 全量 | 任一改动不破坏既有行为；二次运行逐字节一致 |
