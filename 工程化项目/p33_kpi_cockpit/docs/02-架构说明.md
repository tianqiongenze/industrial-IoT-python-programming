# 02 架构说明（TOGAF 四域视角）

> 项目：KPI 驾驶舱

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 让班组长 30 秒看全产线健康度，早会不再翻系统；点击折线点即下钻该时段明细 |
| 数据架构 | clean.csv/合成行 → 筛选 → 派生 KPI（加权良率/效率对标）→ JSON+文本表+HTML/PDF 日报 |
| 应用架构 | app.py（Streamlit 真仪表盘，on_select 选择事件联动）与 run.py（headless CLI）共用 core 纯函数；pipeline 编排并输出分层达标证据 |
| 技术架构 | Python 3.12 + conda pp03；streamlit/plotly/pandas/jinja2/reportlab，缺依赖自动降级；pytest（含 streamlit.testing.v1.AppTest 无头回归） |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `app.py` | Streamlit 仪表盘（TODO-0~5 + A 层联动钻取） | `load_data()`、`st.plotly_chart(on_select="rerun", key="trend_drill")`、`st.dataframe(on_select="rerun", key="alarm_table")` → `core.drill_rows()` |
| `core.py` | 纯函数领域逻辑（零 IO） | `filter_records()` / `compute_kpis()` / `trend()` / `gauge()` / `device_status()` / `alarm_rows()` / `efficiency()` / `anomalies()` / `suggest()` / `drill()` / `drill_rows()` / `drill_fingerprint()` / `tail_rows()` / `render()` |
| `config.py` | YAML 加载 + Settings（改配置不改代码） | `load_config()` / `Settings.rules()` / `require()` / `path()` |
| `data_source.py` | TODO-0 数据源（clean 优先、seed 合成兜底、列级出处） | `load()` → `Dataset.as_df()/as_dicts()` |
| `deps.py` | 可选依赖真探测 | `detect()` / `probe()` / `summary()` |
| `io_utils.py` | JSON/CSV/文本原子落盘 | `write_json()` / `write_text()` / `write_csv_rows()` / `ensure_dir()` |
| `report.py` | 过程报告 + 四段式日报渲染 | `render()` / `save()` / `build_context()` / `render_html()` / `render_pdf()` / `chart_png()` / `bucket()` |
| `schedule.py` | A 层定时产物（crontab/systemd/mailto/移动端） | `next_fire()` / `wait_seconds()` / `mailto()` / `crontab_line()` / `systemd_timer()` / `mobile_note()` |
| `pipeline.py` | 编排 + 分层达标证据（D/C/B/A 数字口径） | `run()` / `build_rows()` / `select_window()` |

## 依赖方向
```
app.py ──┐
         ├─→ pipeline ─→ data_source / report / schedule / deps
run.py ──┘                    ↓
                          core（纯函数，零依赖）
                            ↑
                          config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`/`streamlit`（保持可单测）；
app.py 与 run.py 的过滤/钻取一律走同一份 `core.*`，绝不出现第二套逻辑。

## 关键质量属性
- **可测试性**：core 纯函数 → 单测无需 mock；app.py 用 AppTest 无头回归
- **可配置性**：阈值/KPI 清单/钻取上限与列全部外置 YAML（含 `drill.max_rows`、`drill.detail_columns`）
- **可复现性**：种子固定于配置；证据指纹用 zlib.crc32（builtin hash() 受 PYTHONHASHSEED 随机化，不可当证据）；output/ 不含墙钟数字
