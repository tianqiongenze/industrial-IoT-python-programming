# 05 运行手册

## 1. 环境准备
```bash
conda create -n pp03 python=3.12 -y
conda activate pp03
pip install -r requirements.txt      # 依赖精确锁定见 requirements.txt（本项目无 requirements.lock）
```

## 2. 运行
```bash
python run.py --quiet               # 推荐：只落盘 output/，不在控制台追加打印
python run.py --config config/rules.yaml --quiet
python run.py --outdir output/ --quiet
/opt/anaconda3/envs/pp03/bin/python -m pytest -q    # 61 例全量测试
```
入口参数由 `run.py::main()` 的 argparse 定义，只有 `--config / --outdir / --quiet` 三个
（`--quiet` 之外的那条打印路径当前有缺陷，见 §5）。

## 3. 配置说明（config/rules.yaml）
下表与 `config/rules.yaml` 逐字对齐（键名与取值均以本目录该文件为准），改配置请同步改这里。

| 键 | 含义 | 默认 |
|---|---|---|
| warn | 峭度预警线（工单 B05：健康轴承峭度≈3，破 4 说明波形出现冲击成分） | 4.0 |
| danger | 峭度停机线（冲击密集/剥落发展，建议停机复检） | 6.0 |
| unit | 振动工程量纲口径（报告与台账的单位标注） | mm/s |
| seed | 唯一随机源（信号合成 / 分层切分 / 随机森林），二次运行逐字节一致 | 42 |
| topk | 特征重要性排行等列示条数 | 6 |
| signal.source | 数据链口径：`generator`=故障振动发生器，`clean`=读 P2.1 输出切窗 | generator |
| signal.samples / length | 合成窗口数 / 每窗采样点（clean 链改用 window_length＋window_stride） | 1000 / 1000 |
| signal.fs / f0 / harmonic | 采样率 / 基频 / 二倍频倍数（a16 就落在 2·f0＝16 Hz 谱线上） | 100.0 / 8.0 / 2.0 |
| features.primary / derived | 主特征维数（时域10＋频域15＋统计5）/ 衍生特征维数（A 层） | 30 / 5 |
| redundancy.corr_threshold / keep | 冗余判定阈值（｜r｜ ≥ 阈值，含等号）/ 优先保留口径 | 0.95 / importance |
| vectorization.enabled / targets | AST 向量化闸门开关与扫描面（12 个 `core` 特征函数） | true / 12 项 |
| perf.target_ms / excellent_ms | 1000 样本特征计算验收线：工单《验收标准》良好(C) <100ms／优秀(B) <50ms | 100.0 / 50.0 |

> `perf.excellent_ms` 是**工单优秀(B) 档线**（`<50ms`），取证在报告 §8.5「工单验收四档对照」；
> 它不属于 `pipeline.TIER_REQ` 课堂四级判据（那四行取自教师版 notebook cell-0，100ms 那条是
> 课堂 B 层线）。两套口径字母错一档，各自独立判定，详见 docs/03 §2「四级闸门与墙钟隔离」。

## 5. 常见问题
| 现象 | 原因 | 处置 |
|---|---|---|
| `ModuleNotFoundError` | 未安装依赖 | `pip install -r requirements.txt` |
| 不加 `--quiet` 时结尾抛 `KeyError: -1`（`run.py` 第 31 行把 `pipeline.run()` 返回的 dict 当列表切片） | 打印「结论与建议」的那行代码口径不对；此时 `output/` 已完整落盘 | 用 `python run.py --quiet`，摘要直接看 `output/report.txt` 第 11 节 |
| 报告里箱线图/热力图显示"未生成" | 本机无 matplotlib（两个绘图函数捕获 `ImportError` 返回 `None`） | 装上 matplotlib 重跑；缺图时 A 层会如实判"未达标"，不会假装出图 |
| `signal.source=clean` 报"真实数据链输入不存在" | 未先跑 P2.1，`../p21_pandas_clean/output/clean.csv` 不在 | 先在 p21 项目跑一次，或把 `signal.source` 改回 `generator` |
| 中文乱码 | 控制台编码非 utf-8 | `set PYTHONIOENCODING=utf-8` |
| 图上中文变豆腐块 | 本机无 CJK 字体（`use_cjk()` 探测不到候选字体） | 装 PingFang/Noto Sans CJK 之一，或接受英文标签回退 |
| 配置不生效 | 未传 --config | 使用默认 `config/rules.yaml` |
