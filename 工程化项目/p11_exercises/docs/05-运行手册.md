# 05 运行手册

> 项目：Python 五题闯关（工单 P1.1）

## 1. 环境准备
```bash
conda activate pp03                     # 课程环境：Python 3.12.11
python -V                               # 期望 3.12.x
/opt/anaconda3/envs/pp03/bin/python -m pytest --version   # pytest 9.1.1
pip install -r requirements.txt         # 仅 PyYAML 是可选依赖（缺了自动降级）
```
无 PyYAML 也能跑：`config.yaml_lite`（`config.py:116`）会接管，报告首节写明"解析器"。
课堂环境**未安装** pylint/flake8/black/pre-commit（实测 `python -m pylint --version`
报 No module named pylint），故规范分由内置 `stylecheck` 给出并明确标注口径。

## 2. 运行
```bash
python run.py                       # 默认：读 config/rules.yaml，写 output/
python run.py --tier C              # 按工单"良好(C)"档验收线高亮（D 及格/C 良好/B 优秀/A 超优）
python run.py --quiet               # 只落盘，不打印正文
python run.py --list-tools          # 只探测四个规范工具是否可用（不产出文件）
python run.py --no-notes            # 不重写 docs/09 迁移笔记（笔记项按未达标显示）
python run.py --config 路径 --outdir 路径 --root 路径
python run.py --help                # 全部旗标（cli.py:18）
```
以上旗标全部有子进程级测试覆盖并断言退出码 0
（`tests/test_pipeline_cli.py::test_cli_flags_exit_zero`）。
`--tier` 只影响"本轮请求层"的高亮标注与结论行措辞，四档证据行始终全部打印。

## 6. 常见问题
| 现象 | 原因 | 处置 |
|---|---|---|
| `配置校验失败: 阈值顺序颠倒` | `warn >= danger` | 改回 `warn < danger`（`config.py:254`） |
| `配置校验失败: PEP 8 分层线顺序颠倒` | `pep8_pass_rate_d > pep8_pass_rate_b` | 让及格(D) 线 ≤ 优秀(B) 线（默认 75.0 ≤ 85.0） |
| `配置校验失败: naming_meaningful_rate 必须在 0~100 之间` | 命名线写错（如 101） | 回到 0~100 区间（默认 90.0） |
| 某档判"未达标"但不知缺哪条 | 该档证据行有 ✘ | 看 `report.txt`【X · 名称层】块的首行汇总（工单要求+实测数字）与逐条 `[✔]/[✘]` 明细，或 `result.json` 的 `tiers[t]` |
| 报告里 pylint 一栏写"不可用" | 课堂环境未装 pylint | 正常现象；装上 pylint 后 `stylecheck.pylint_score()` 自动给出真实分数 |
| 想验证死配置检测 | 故意加 `foo: 1` | 报告首节出现"忽略未识别的顶层键(死配置)" |
| 中文乱码 | 控制台编码非 utf-8 | Windows 用 `set PYTHONIOENCODING=utf-8` |
| 二次运行 diff 不为空 | 有随机/时间源混入 | 属缺陷，按 docs/04 §3 的确定性用例回查 |
